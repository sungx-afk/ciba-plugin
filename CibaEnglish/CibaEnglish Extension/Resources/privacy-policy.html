糍粑记忆卡 + 视频字幕OCR — 隐私政策

最后更新日期：2026年8月25日

1. 概述

糍粑记忆卡 + 视频字幕OCR（以下简称"本扩展"）是一款帮助用户在外语视频网站自动识别字幕并查词翻译、在任意网页划词查询糍粑词典并将生词加入生词本的浏览器扩展程序。 本隐私政策说明我们如何收集、使用和保护您的数据。

2. 我们收集的数据

本扩展仅在您主动使用功能时收集以下数据：

  • 选中文本：您在网页上划词选中并触发查词/加卡时，该段文本会被发送到服务器。
  • 字幕截图：在视频网站暂停时，扩展会截取视频画面中的字幕区域用于本地 OCR 识别。识别后的文字结果用于查词和加入生词本。
  • 字幕截图图片（可选）：若您在设置中主动开启"允许上传字幕截图"选项，截图图片会连同生词一起上传到云端以保存单词卡片。该选项默认关闭，您可随时在扩展设置中关闭。
  • 登录凭证：您通过微信扫码登录后，扩展会存储一个登录 Token，用于向服务器验证您的身份。

3. 数据的使用方式

收集的数据仅用于以下目的：

  • 将选中文本发送到 cibaen.com 服务器查询单词释义
  • 将视频字幕截图发送到 cibaen.com OCR 接口进行文字识别
  • 将生词和字幕截图（如您已开启）保存到您的糍粑生词本
  • 维持您的登录状态

我们不会将您的数据用于上述用途之外的任何其他目的。

4. 数据存储与共享

  • 所有数据仅传输至 cibaen.com 官方服务器（包括其 API 和 OCR 服务接口）。
  • 若您开启了截图上传功能，截图图片会经由 upload.qiniup.com（七牛云对象存储）上传并存储。
  • 我们不会将您的数据出售、出租或共享给任何第三方广告商或数据分析平台。
  • 您的登录 Token 仅存储在您的浏览器本地（chrome.storage.local），不会同步到其他设备。
  • 登录 Token 在您主动退出登录或卸载扩展时清除；云端保存的生词卡片数据，您可在糍粑网站或小程序中管理并删除。

5. 用户控制权

  • 您可以在扩展设置页面随时关闭"添加单词本时上传视频截图"选项，关闭后截图将不再上传。
  • 您可以在扩展设置页面重置所有配置。
  • 您可以通过微信退出登录，清除本地存储的 Token。
  • 卸载扩展后，所有本地存储的数据将被自动清除。

6. 数据处理方式的变更

若未来本扩展的数据处理方式发生变更（例如新增数据收集类型或变更用途），我们将通过以下方式之一主动告知您：

  • 扩展内弹窗或通知
  • 更新日志中显著说明
  • 本隐私政策页面的更新
